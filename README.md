# pr-review-testbed

A deliberately flawed repository used to exercise
[pr-review-assistant](https://github.com/MichaelFu1998-create/pr-review-assistant).

Pull requests here introduce known defects on purpose. The point is to check that
the reviewer finds the real ones, proposes applyable fixes where it can, and — just
as importantly — stays quiet about formatting and naming.

**Do not copy code from this repository.**
